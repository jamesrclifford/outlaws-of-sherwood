# Outlaws of Sherwood

A turn-based Robin Hood RPG for Android and iOS, built with Godot 4 and GDScript, in pixel art.

Lead Robin's band across a strategic map of Nottinghamshire, rob tax wagons, rescue captured friends, recruit heroes from the old stories, and outwit the Sheriff of Nottingham and Sir Guy of Gisborne.

The full design and roadmap are in [docs/design-plan.md](docs/design-plan.md).

## Running

1. Install [Godot 4.7](https://godotengine.org/download).
2. Open this folder in Godot and press Play, or run `godot --path .`.

## Layout

| Folder | What lives there |
|---|---|
| `core/` | Game rules with no UI: combat, units, mission generation and play, the campaign (map, days, villains, saves), data loading. Deterministic for a given seed. |
| `data/` | Heroes, enemies, abilities, encounters, locations, mission templates, traps, the map, items, economy numbers and story missions (`stories.json`: the starting band and the hand-written legends that win new companions; `tales.json`: 40 more legends from the ballads, posted two at a time as reputation and earlier tales allow) as JSON. New content goes here, not in code. |
| `scenes/` | Screens: menu, strategic map, mission path, battle. |
| `assets/sprites/` | 32x32 unit sprites, generated by `python3 tools/make_sprites.py` (edit the drawing code there, then rerun). |
| `assets/backdrops/`, `assets/map/`, `assets/ui/` | Battle backdrops (one per location), the strategic map, the title screen, mission path medallions and wooden UI frames, generated by `python3 tools/make_scenery.py`. Rerun it after changing `data/map.json`, since roads and place icons are painted into the map. |
| `scenes/ui/style.gd` | The shared theme: wooden buttons, dark panels, parchment plaques. |
| `assets/fonts/` | The pixel font, a BMFont drawn glyph by glyph in `tools/make_font.py` and set project-wide in `project.godot`. |
| `assets/items/`, `assets/fx/` | Armory gear icons and the arrows, bolts and nets that fly in battle, from `tools/make_scenery.py`. |
| `tests/` | Headless tests: `GODOT=/path/to/godot tests/run.sh`. `tests/mission_smoke.gd`, `tests/map_smoke.gd` and `tests/shop_smoke.gd` play through the real UI. |

## Android

`tools/build_android.sh` builds a signed APK you can install on a phone (`build/OutlawsOfSherwood-<version>.apk`).
It needs Godot 4.7.1 and Java, but no Android SDK: it downloads the export templates and
[uber-apk-signer](https://github.com/patrickfav/uber-apk-signer) on first run.

    GODOT=/path/to/godot KEYSTORE=/path/to/outlaws-sideload.keystore tools/build_android.sh

Sign every build with the same keystore, or Android refuses to install it over an earlier one.
The version shown on the phone is `version/name` in `export_presets.cfg`; bump `version/code` with it.
